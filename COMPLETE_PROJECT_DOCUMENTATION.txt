1. PROJECT OVERVIEW & SCOPE
================================================================

1.1 PROJECT VISION
------------------
The Safety Detector is an AI-powered surveillance system designed to automatically detect women harassment incidents in real-time using computer vision and artificial intelligence. The system aims to provide immediate alerts to authorities and create evidence for legal proceedings.

1.2 PROJECT SCOPE
-----------------
PRIMARY OBJECTIVES:
- Real-time harassment detection from live camera feeds
- Comprehensive video file analysis for post-incident investigation
- Automatic alert generation with evidence collection
- Detailed performance logging and analysis
- Privacy-conscious design with no facial recognition

FUNCTIONAL REQUIREMENTS:
- Live camera monitoring with real-time processing
- Video file upload and analysis capabilities
- Modern web interface with dashboard and controls
- Person detection and tracking
- Behavioral pattern analysis
- Alert generation and evidence preservation
- Cost-saving auto-stop mechanism when alerts detected
- Parallel processing for performance enhancement
- Video chunking for ultra-fast analysis
- Performance metrics and logging
- User-friendly interface and controls

NON-FUNCTIONAL REQUIREMENTS:
- Processing speed: 15-30 FPS for live monitoring
- Detection accuracy: >85% confidence threshold
- Response time: <3 seconds for alert generation
- Privacy compliance: No personal identification
- Scalability: Support multiple camera sources
- Reliability: 24/7 operation capability

1.3 TARGET USE CASES
-------------------
- Public space monitoring (streets, parks, transport)
- Educational institution security
- Workplace safety monitoring
- Event and gathering surveillance
- Investigation support for law enforcement

4. AI MODELS & ALGORITHMS
================================================================

4.1 YOLOV8 PERSON DETECTION MODEL
---------------------------------

MODEL SPECIFICATIONS:
- Architecture: You Only Look Once Version 8 (Nano variant)
- Model File: yolov8n.pt (6.23MB)
- Input Resolution: Dynamic (optimized for speed)
- Output Classes: 80 COCO classes (focusing on 'person' class)
- Inference Speed: ~0.098 seconds per frame
- Confidence Threshold: 0.5 (50% minimum confidence)

TECHNICAL DETAILS:
The YOLOv8 model uses a single neural network to predict bounding boxes and class probabilities directly from full images in one evaluation. The model is specifically trained on the COCO dataset with extensive person detection examples.

DETECTION PROCESS:
1. Image Preprocessing: Frame normalization and resizing
2. Neural Network Inference: Forward pass through YOLOv8 architecture
3. Non-Maximum Suppression: Removing duplicate detections
4. Confidence Filtering: Keeping only high-confidence detections
5. Bounding Box Extraction: Coordinate extraction for detected persons

WHY YOLOV8 CHOSEN:
- Real-time performance: Optimized for speed
- High accuracy: State-of-the-art detection performance
- Robustness: Works across various lighting and angle conditions
- No facial dependency: Detects full body silhouettes
- Privacy-friendly: No personal identification features

PERSON DETECTION CAPABILITIES:
- 360-degree detection (front, back, side views)
- Multiple person tracking in single frame
- Occlusion handling (partially hidden persons)
- Scale invariance (near and far detection)
- Pose independence (standing, walking, sitting)

4.2 GOOGLE GEMINI VISION AI MODEL
---------------------------------

MODEL SPECIFICATIONS:
- Model Version: Gemini-1.5-Flash
- Input Modality: Text + Image (multimodal)
- Processing Type: Cloud-based inference
- Response Time: 1-3 seconds average
- Context Window: Large context for detailed analysis
- Output Format: Structured text responses

HARASSMENT DETECTION LOGIC:
The system uses carefully crafted prompts to guide Gemini's analysis:

PROMPT STRUCTURE:
"Look at this image carefully. I need you to check if there is any harassment happening.

Look for these warning signs:
- Someone following another person closely
- Someone blocking another person's path
- Aggressive body language or gestures
- Someone cornering another person
- Any threatening behavior

Answer with just:
- 'ALERT' if you see potential harassment
- 'SAFE' if everything looks normal

Then give a short reason why."

BEHAVIORAL PATTERNS ANALYZED:
1. Spatial Relationships: Proximity violations, personal space invasion
2. Movement Patterns: Following behavior, stalking indicators
3. Body Language: Aggressive postures, threatening gestures
4. Environmental Context: Isolated locations, escape route blocking
5. Interaction Dynamics: Power imbalances, intimidation signs

WHY GEMINI CHOSEN:
- Multimodal capabilities: Processes both visual and contextual information
- Advanced reasoning: Understands complex behavioral patterns
- Natural language output: Provides explanatory responses
- High accuracy: Trained on vast datasets of human interactions
- Contextual understanding: Considers environmental and social factors

CONFIDENCE AND RELIABILITY:
- Binary classification: Clear ALERT/SAFE decisions
- Reasoning provided: Explanations for each decision
- Context awareness: Considers multiple factors simultaneously
- False positive minimization: Conservative approach to alerts

7. COST-SAVING AUTO-STOP MECHANISM
================================================================

7.1 OVERVIEW
------------
The Safety Detector includes intelligent cost-saving features that automatically stop expensive AI analysis once harassment is detected, since the primary goal is incident detection rather than complete video analysis.

7.2 VIDEO ANALYSIS AUTO-STOP
----------------------------

TRIGGER CONDITIONS:
- Harassment alert detected by AI model
- Alert evidence captured and saved
- Current progress and statistics calculated

AUTO-STOP PROCESS:
1. Immediate analysis suspension upon alert detection
2. Display comprehensive status information:
   - Current progress percentage
   - Frames processed vs total frames
   - Analysis time elapsed
   - AI checks performed so far
   - Cost savings information

3. User prompt with three options:
   - 'y' or 'yes': Continue full analysis
   - 'n' or 'no' or Enter: Stop analysis (DEFAULT)
   - 's' or 'summary': Generate summary and stop
   - Ctrl+C: Emergency stop

COST SAVINGS CALCULATION:
- Remaining frames: total_frames - current_frame
- Estimated time saved: remaining_frames × average_frame_time
- Potential AI calls saved: remaining_frames_with_people × analysis_frequency

EXAMPLE OUTPUT:
```
🚨 HARASSMENT ALERT DETECTED! 🚨
💰 Stopping analysis to save AI costs...
📊 Current progress: 15.3% (65/420 frames)
⏱️ Analysis time so far: 23.5 seconds
🔍 AI checks performed: 12

Continue analysis? (y/n/s): [n]
```

7.3 LIVE CAMERA AUTO-PAUSE
--------------------------

TRIGGER CONDITIONS:
- Real-time harassment alert detected
- Evidence screenshot saved automatically
- Alert data logged to session

AUTO-PAUSE FEATURES:
1. Visual indicators on camera feed:
   - Red "ALERT DETECTED!" warning
   - Alert message display
   - Continue/quit instructions
   - Cost-saving notification

2. Enhanced keyboard controls:
   - 'c': Continue monitoring after alert
   - 'q': Quit monitoring session
   - 's': Save current frame
   - 'l': Save session log

7.4 COST IMPACT ANALYSIS
------------------------

TYPICAL SAVINGS SCENARIOS:

Early Detection (10% through video):
- Original cost: 100% of video analysis
- With auto-stop: 10% analysis cost
- Savings: 90% cost reduction

Mid-point Detection (50% through video):

- With auto-stop: 50% analysis cost
- Savings: 50% cost reduction

API CALL REDUCTION:

8. FUNCTION-BY-FUNCTION DOCUMENTATION

7.1 PERSON_DETECTOR.PY FUNCTIONS
--------------------------------

load_person_detector()
PURPOSE: Initialize and load the YOLOv8 person detection model
PARAMETERS: None
RETURNS: YOLO model object
PROCESS:
1. Print initialization status message
2. Configure PyTorch compatibility for weights loading
3. Create YOLO model instance with yolov8n.pt weights
4. Handle model download if weights not present
5. Return initialized model object
ERROR HANDLING: PyTorch compatibility issues, download failures
PERFORMANCE: ~2 seconds initial load, <0.1s subsequent calls

find_people_in_frame(model, frame)
PURPOSE: Detect all people in a video frame using YOLO
PARAMETERS: 
  - model: Loaded YOLO model object
  - frame: OpenCV image array (BGR format)
RETURNS: List of dictionaries containing person detection data
PROCESS:
1. Run YOLO inference on input frame
2. Iterate through detection results
3. Filter for 'person' class (class ID 0)
4. Apply confidence threshold filtering (>0.5)
5. Extract bounding box coordinates (x1, y1, x2, y2)
6. Store confidence scores for each detection
7. Return structured detection data
DATA STRUCTURE: [{'x1': int, 'y1': int, 'x2': int, 'y2': int, 'confidence': float}]
PERFORMANCE: ~0.098 seconds per frame average

draw_person_boxes(frame, people_list)
PURPOSE: Draw bounding boxes around detected people
PARAMETERS:
  - frame: OpenCV image array to draw on
  - people_list: List of person detection dictionaries
RETURNS: Modified frame with drawn bounding boxes
PROCESS:
1. Iterate through each person detection
2. Extract bounding box coordinates
3. Draw green rectangle around person
4. Add confidence score text above bounding box
5. Use OpenCV drawing functions (rectangle, putText)
6. Return modified frame
VISUAL OUTPUT: Green boxes with confidence labels
PERFORMANCE: <0.01 seconds per frame

------------------------------------

- Solution: Check camera connection and permissions

E002: YOLO model download failed
- Solution: Check internet connection and retry

E003: Gemini API authentication failed
- Solution: Verify API key in .env file

E004: Video file format not supported
- Solution: Convert to supported format (MP4, AVI, MOV)

E005: Insufficient disk space
- Solution: Clear old logs and evidence files

E006: Camera initialization failed
- Solution: Run camera_diagnostics.py to troubleshoot
